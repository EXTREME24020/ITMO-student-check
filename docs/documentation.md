# Проектная документация 

## Общее описание:
Бот проверяет является ли пользователь телеграм студентом ИТМО или нет

## Команды:
### check_itmo_student:
- Проверяем раздел "о себе" профиля телеграм пользователя, который использовал команду /itmostudent, на наличие упоминания ИТМО и отправляем в чат сообщение с ответом: является студентом ИТМО или не является
##### Параметры фкнкции: 
- message - сообщение, через обработку которого, мы получим айди пользователя и сможем посмотреть его раздел профиля "о себе"
